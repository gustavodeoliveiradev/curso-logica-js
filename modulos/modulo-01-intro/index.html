Módulo 01

O que é lógica de programação

Um computador só segue instruções

Programar não é decorar comandos de uma linguagem. É aprender a quebrar um problema em passos pequenos e claros o suficiente pra que um computador — que não deduz nada sozinho — consiga seguir. Isso é lógica de programação.

Entrada, processamento e saída

Quase todo programa segue esse fluxo:

  • Entrada: os dados que o programa recebe (um número digitado, um clique, um arquivo)
  • Processamento: o que o programa faz com esses dados (calcula, compara, transforma)
  • Saída: o resultado que o programa devolve (um texto na tela, um som, um arquivo salvo)

O que é um algoritmo?

Um algoritmo é uma sequência finita e ordenada de passos pra resolver um problema. Uma receita de bolo é um algoritmo. Um tutorial de troca de pneu é um algoritmo. No código ao lado, você vai ver um algoritmo bem simples: descobrir se um número é par ou ímpar.

Testando na prática

Clique em "▶ Executar" no bloco de código ao lado. O JavaScript de verdade vai rodar a função verificarSePar() e mostrar o resultado logo abaixo, no console simulado.

exemplo.js 
// Recebe um número e diz se ele é par ou ímpar
function verificarSePar(numero) {
  // O resto da divisão por 2 revela isso
  const resto = numero % 2;

  if (resto === 0) {
    return `${numero} é par`;
  } else {
    return `${numero} é ímpar`;
  }
}
