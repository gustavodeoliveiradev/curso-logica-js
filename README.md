# Lógica de Programação com JS

Curso gratuito e modular de lógica de programação, ensinado com exemplos em JavaScript.

## Estrutura do projeto

```
curso-logica-js/
├── index.html              → landing page do curso
├── modulos/                → cada módulo do curso vive em sua própria pasta
├── assets/
│   ├── css/
│   │   ├── base.css        → variáveis de cor, tipografia, reset
│   │   ├── layout.css      → estrutura das seções (header, hero, grid, footer)
│   │   └── componentes.css → peças reutilizáveis (cards, botões, terminal)
│   └── js/
│       └── tema.js         → alternância entre tema claro e escuro
```
